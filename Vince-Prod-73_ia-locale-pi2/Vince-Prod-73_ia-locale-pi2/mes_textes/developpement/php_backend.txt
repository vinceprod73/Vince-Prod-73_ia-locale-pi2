Structure d'un script PHP : ouvre le code avec <?php et utilise echo htmlspecialchars($texte, ENT_QUOTES, 'UTF-8'); pour afficher du texte en evitant les failles XSS. Les variables commencent toujours par $.

Recuperer un formulaire en PHP : lis $_POST['champ'] pour un formulaire POST ou $_GET['param'] pour un parametre d'URL. Verifie toujours l'existence avec isset($_POST['champ']) avant d'utiliser la valeur.

Connexion base de donnees PDO en PHP : utilise $pdo = new PDO('mysql:host=localhost;dbname=base;charset=utf8', 'user', 'pass'); puis $stmt = $pdo->prepare('SELECT * FROM users WHERE id = ?'); $stmt->execute([$id]); pour des requetes securisees.

Lire et ecrire JSON en PHP : utilise json_decode($chaine, true) pour convertir du JSON en tableau associatif PHP, et json_encode($tableau, JSON_UNESCAPED_UNICODE) pour generer une reponse API propre.
