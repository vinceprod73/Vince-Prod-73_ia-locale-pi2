# Vince-Prod-73_ia-locale-pi2
Petite IA 100 % locale, sans cloud ni clé API, conçue pour le Raspberry Pi 2 (1 Go de RAM).  • Recherche dans tes propres fiches texte (.txt, .md) et scripts • Génération de petits programmes automatisés avec llama.cpp + Qwen2.5-Coder 0.5B • Interface web simple (Flask) sur le réseau local • Installation en une commande + services systemd
